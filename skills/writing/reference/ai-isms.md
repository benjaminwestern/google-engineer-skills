# AI-isms to Remove

These words, phrases and patterns make prose read as generated. Remove every one. Rewrite the sentence with a plain, specific word. Do not swap in a synonym of the banned word, because the pattern survives the swap.

Code, quoted source material and proper names are exempt. A product literally named "Journey Builder" keeps its name.

## Banned Words

Each banned word below has a plainer way to say what it usually means:

| Banned | Write Instead |
| --- | --- |
| leverage | use |
| robust | name the property: tested, redundant, validated |
| seamless, seamlessly | say what happens without a step: "with no second sign-in" |
| crucial, pivotal, vital, key (as an adjective) | say why it matters, or drop the word |
| ensure | the direct verb: checks, blocks, requires, sets |
| delve | examine, read, test |
| landscape, realm | name the actual set: "the provider market", "the estate" |
| journey | name the process: onboarding, migration, sign-in |
| unlock, empower, elevate | say what the reader can now do |
| harness | use |
| streamline | name the step removed |
| cutting-edge | name the capability or the release date |
| game-changer | state the measured effect |
| holistic | name what is covered |
| synergy | name the shared benefit |
| tapestry | delete the metaphor |
| testament | state the evidence |
| navigate (figurative) | handle, work through, choose |
| foster, bolster | name the action: train, fund, add |

## Banned Phrases

- "It is worth noting", "importantly", "notably". State the fact.
- "In short", "in summary", "at its core". Delete the phrase, and delete the sentence if it only summarises.
- "In today's ...", "in the modern ...". Delete the scene-setting.
- "When it comes to X". Start with X.
- "Not just X but Y", "not only X but also Y". State Y, and X if it matters.
- "Plays a key role", "serves as", "stands as". Use "is" or the real verb.
- "A wide range of". Name the range, or say "many".
- "Whether you are X or Y". Address the actual reader.
- "Let's dive in", "here's the thing". Delete.

## Banned Patterns

- Padded groups of three. "Fast, reliable and scalable" is filler unless each word carries a separate, supported claim.
- A closing sentence that repeats the section. End when the content ends.
- A rhetorical question as a transition ("So what does this mean?").
- A contrast construction ("It is not X. It is Y.", "X, not Y" as a flourish).
- An aphorism or quotable generalisation.
- An item count in prose ("three pillars", "two archetypes").
- Reason glue phrases: "is what makes", "which is why", "That is why", "is deliberate", "by design".
- Formulaic openers: "This page states", "This section describes", "The table gives", "The table lists", "A reviewer can test", "These properties", "These rules".
- "Holds" as a general-purpose verb.
- "Rather than" more than about once per section.
